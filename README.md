# Atividade prática: Aplicações Móveis com Expo

## Objetivo
Criar uma aplicação utilizando Expo que gera cards profissionais e implementa navegação com o Expo

## Telas da Aplicação

### Tela Inicial
Exibe a interface principal, onde o usuário pode iniciar a criação dos cards.  
![Tela Inicial](assets/tela-inicial.png)

### Tela de Cadastro
Permite ao usuário preencher informações para criar o card.  
![Tela Cadastro](assets/tela-cadastro.png)

### Tela de Sucesso
Confirmação de que o card foi criado com sucesso.  
![Tela Sucesso](assets/tela-sucesso.png)
